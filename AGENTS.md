# Weave

For Personal Planet homepage or globe work, read `skills/personal-planet-ui/SKILL.md` first. This visual guidance does not apply to backend-only changes.

The frontend lives in `frontend/`; the existing Python backend lives in `backend/`. Follow the phase explicitly requested by the user. Current homepage work covers the eight-region world, terrain and primitive landmarks; content routing remains a later step.

Record each approved plan and completed change in the independent private Git repository at `weave_private/logs/`, using the current date. Keep it separate from the main repository, and never record API keys, tokens, passwords, or full authorization headers.
