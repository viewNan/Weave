对，这一步就要开始像“世界设定集”了。
我们最好不要只停留在“有几个大陆”，而是直接规定：

* **每块区域的大概面积**
* **轮廓形状**
* **海岸线风格**
* **有没有附属小岛**
* **地形起伏**
* **默认熟练度颜色**
* **建筑密度倾向**

这样 Codex / GPT-6 才不会自由发挥得太散。

# 一、先定整个地球的总规则

## 1. 整体比例

我建议：

* **海洋：60%**
* **陆地：32%**
* **冰川 / 极地：8%**

这样球不会太满，仍然有“呼吸感”。

---

## 2. 大陆数量结构

固定为：

* **3 个大大陆**
* **2 个中型大陆**
* **1 个小大陆**
* **1 组群岛**
* **1 个极地冰川区域**
* **若干灵感小岛**

也就是：

### 大大陆

* Research
* Workbench
* Living

### 中型

* Growth
* Archive

### 小型 / 群岛

* Hobby Isles
* Spark Islands

### 特殊

* Exploration Ice

---

## 3. 形状总体原则

你这个世界不要每块都长得差不多。
要故意拉开差异。

所以我建议：

* **Research**：边缘较崎岖，有半岛和山脊
* **Workbench**：块状、台地感、海湾多
* **Living**：最完整、最圆润、最“稳定”
* **Growth**：有向上延伸感，像在攀升
* **Hobby Isles**：碎片化群岛
* **Archive**：紧凑、安静、边界清晰
* **Exploration Ice**：破碎冰盖 + 冰岛裂片

# 二、每块大陆的详细规定

---

# 1）Research 研究大陆

## 定位

你的**主场之一**。
偏学术、深度、高知识密度。

## 面积

**最大之一**
建议占全部陆地的 **18%**

## 形状

* 整体是一个**不规则盾牌形 / 梨形大陆**
* 上窄下宽
* 一侧有明显外伸半岛
* 不要太圆
* 边缘要有起伏

你可以理解成：

```text
      /\__
   __/    \_
  /          \
 |    /\      |
 |   /  \     |
  \__    __--/
     \__/
```

## 海岸线风格

* **中度崎岖**
* 有 **2~3 个海湾**
* 有 **1 条长半岛**
* 岸边可以有 **2~4 个小附属岛**

也就是说它不是完整圆块，而是：

> 有深度、有研究感的大陆。

## 地形

* 中心有一条**低多边形山脊**
* 主建筑在高地
* 周围有缓坡和平原
* 海岸附近比较低平

### 地形层级

* 海洋
* 海岸
* 平原
* 林地
* 山脊
* 主建筑高台

## 核心建筑

* **天文台 / 研究塔 / 图书馆复合体**
* 高于周边其他建筑
* 作为这个大陆的绝对视觉中心

## 周边元素

* 3~6 个小建筑
* 小书屋 / 实验楼 / 资料馆
* 少量树
* 清晰小路

## 默认熟练度颜色

因为这是你的核心区之一，默认偏熟：

* 基础地表：`#93A883`
* 熟练区域：`#718A66`
* 海岸过渡：`#F6E2D7`
* 山地：`#B7B09E`

## 气质关键词

* intellectual
* structured
* elevated
* calm
* grounded

---

# 2）Workbench 工作工坊大陆

## 定位

你的**开发 / 项目 / 动手实现中心**。

## 面积

**第二大**
占全部陆地的 **16%**

## 形状

* 整体更像一个**块状台地大陆**
* 比 Research 更“人为建造感”
* 有几个切面感很强的边缘
* 轮廓不要太自然，要略有几何味

大概像：

```text
   ______
 _/      \__
/  __  __   \
| |  ||  |   |
| |__||__|  /
 \__     __/
    \___/
```

## 海岸线风格

* **海湾较多**
* 有 **港口感凹口**
* 可以有 **人工平台式边缘**
* 有 1~2 个近岸小岛

比起 Research，它更像：

> 被建设过的大陆。

## 地形

* 不用太多山
* 以**台地 / 阶梯地形 / 平台**为主
* 有少量岩石和起伏
* 主建筑可以立在一块中央平台上

## 核心建筑

* **工坊 / 工作室 / 中央控制塔**
* 形状略模块化
* 看起来是“造东西的地方”

## 周边元素

* 4~8 个小建筑
* 模块化小屋
* 小桥 / 平台 / 小塔
* 路比较明显
* 房子密度在所有大陆里偏高

## 默认熟练度颜色

这是高建设度区域，但不一定最绿，可以稍微偏“建设感”：

* 基础地表：`#B8C4A3`
* 高熟练建设区：`#718A66`
* 平台岩地：`#C8BBAF`
* 高亮点缀：`#FF9558`

## 气质关键词

* modular
* built-up
* practical
* active
* maker-like

---

# 3）Living 生活大陆

## 定位

日常、生活、饮食、计划、居住感最强的区域。

## 面积

**最大之一**
占全部陆地的 **18%**

## 形状

* 这是所有大陆里**最圆润、最完整**的一块
* 整体像一个柔和的豆形 / 花生形
* 不要太破碎
* 看起来最安心、最稳定

大概像：

```text
    ______
  /        \
 /          \
|            |
|            |
 \          /
  \____ ____/
       \/
```

## 海岸线风格

* **最平滑**
* 只有轻微起伏
* 可以有 **一个浅海湾**
* 附属小岛很少，最多 1~2 个小岛

它应该一看就感觉：

> 很宜居，很舒展。

## 地形

* 平原为主
* 少量缓丘
* 少量树林
* 不要高山
* 海边可以有柔和海岸带

## 核心建筑

* **主宅 / 温暖小屋 / 生活中心**
* 体量中等，不要像城堡
* 温柔、亲切

## 周边元素

* 3~7 个小房子
* 小咖啡馆
* 小菜园
* 树比较多
* 小路自然弯曲

## 默认熟练度颜色

生活区通常是稳定高频，但不一定像 Research 那样知识密度强，所以建议：

* 基础地表：`#B8C4A3`
* 熟悉区：`#93A883`
* 高熟悉生活主区：`#718A66`
* 海岸/沙地：`#F6E2D7`

## 气质关键词

* warm
* gentle
* lived-in
* soft
* welcoming

---

# 4）Growth 成长大陆

## 定位

学习、语言、求职、训练、自我成长。

## 面积

**中型**
占全部陆地的 **12%**

## 形状

* 整体应该有一种“向上延伸”的感觉
* 可以做成**弯月形 / 长叶形**
* 不要太宽，略修长

比如：

```text
    __
  _/  \__
 /       \__
|           \
 \__         |
    \__   __/
       \_/
```

## 海岸线风格

* 中等完整
* 略有弯曲
* 少量小湾口
* 可以有 1 条向外伸的小尖角

## 地形

* 丘陵为主
* 一条缓缓上升的山坡
* 主建筑在相对高点
* 有“攀登感”

## 核心建筑

* **灯塔 / 学院塔 / 训练塔**

## 周边元素

* 2~5 个小建筑
* 旗帜
* 上坡小径
* 小平台

## 默认熟练度颜色

成长区应该更像“正在变绿”：

* 基础地表：`#D8D4C3`
* 发展中：`#B8C4A3`
* 成熟点：`#93A883`

这个区域不一定一开始很绿，后面可以成长得很明显。

## 气质关键词

* upward
* disciplined
* evolving
* hopeful

---

# 5）Hobby Isles 兴趣群岛

## 定位

爱好、轻探索、山、运动、设计灵感等。

## 面积

总面积占全部陆地的 **10%**
但不是一个整体，而是**4~7 个岛**组成的群岛。

## 形状

* 不做成单独大陆
* 做成一串大小不同的岛链
* 其中：

  * 1 个主岛
  * 2~3 个中岛
  * 2~3 个小岛

## 海岸线风格

* **最碎**
* 岛屿边缘有变化
* 有很多小海湾、小突出
* 很适合做山地和观景点

## 地形

* 起伏明显
* 岛上可以有小山
* 树比较多
* 海岸悬崖可以稍微明显一点

## 核心建筑

* 主岛有 **营地 / 山屋 / 展亭**
* 其他岛不一定有建筑，可以只有自然元素

## 周边元素

* 树
* 小桥
* 风车
* 帐篷
* 小观景台

## 默认熟练度颜色

这个区域应该更自由，绿度层次丰富：

* 裸地：`#D8D4C3`
* 普通植被：`#B8C4A3`
* 熟悉兴趣区：`#93A883`
* 最熟岛：`#718A66`

## 气质关键词

* playful
* exploratory
* scenic
* varied

---

# 6）Archive 记忆档案大陆

## 定位

归档、复盘、旧记录、长线积累。

## 面积

**小到中型**
占全部陆地的 **8%**

## 形状

* 紧凑
* 边界比较清晰
* 接近椭圆 / 圆角矩形感
* 不要太碎

大概像：

```text
   ________
 /          \
|            |
|            |
 \__________/
```

## 海岸线风格

* 相对完整
* 只有轻微凹口
* 附属岛最多 1 个

它要有“整理好”“收纳好”的感觉。

## 地形

* 平缓
* 少量台地
* 不要高山
* 建筑比树稍多，但整体安静

## 核心建筑

* **档案馆 / 记忆馆 / 收藏塔**

## 周边元素

* 2~4 个小仓库
* 安静树木
* 笔直一点的小路

## 默认熟练度颜色

* 基础地表：`#B8C4A3`
* 归档成熟区：`#93A883`
* 建筑周边：`#F6E2D7`

## 气质关键词

* orderly
* quiet
* reflective
* preserved

---

# 7）Exploration Ice 极地冰川

## 定位

探索、未来、未开发、someday/maybe。

## 面积

占整个球体表面的 **8%** 左右
可以做成：

* 1 个主极地冰盖
* 3~6 块破碎冰岛

## 形状

* 不规则冰盖
* 边缘破碎
* 裂片感明显
* 不要太圆整

## 海岸线风格

严格说是“冰缘”：

* 裂口
* 碎边
* 冰块漂浮

## 地形

* 低起伏冰面
* 局部凸起
* 冰台
* 冰脊

## 核心建筑

* **观测站 / 探索营地 / 冰上信标**
* 很小，不成熟

## 周边元素

* 碎冰
* 极少建筑
* 几乎没树

## 默认颜色

* 主冰面：`#FBF5F2`
* 冰影：`#EAF1EF`
* 冷色阴影：`#DCE7E5`

## 气质关键词

* unbuilt
* distant
* potential
* mysterious

---

# 8）Spark Islands 灵感小岛

## 定位

碎片灵感 / inbox / draft / 暂未归类。

## 面积

总共只占 **2~3%**
做成 **6~12 个超小岛** 散落在海面。

## 形状

* 都很小
* 形状随意
* 像漂浮碎片

## 风格

* 低建筑密度
* 小灯塔 / 小信箱 / 小牌子
* 更多是“提示性存在”

这个最好统一成 4 级。

---

## 熟练度 Level 0：未开发

* 地面：`#D8D4C3`
* 树较多
* 房子很少
* 路几乎没有

## 熟练度 Level 1：起步

* 地面：`#B8C4A3`
* 1~2 个小建筑
* 少量路

## 熟练度 Level 2：熟悉

* 地面：`#93A883`
* 3~5 个小建筑
* 路网变清楚

## 熟练度 Level 3：主场

* 地面：`#718A66`
* 建筑较多
* 结构最清楚
* 可以有小广场 / 中心平台

* Research

* Archive
