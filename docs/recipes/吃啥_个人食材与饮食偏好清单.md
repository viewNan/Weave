# 吃啥｜个人食材与饮食偏好清单

更新时间：2026-09-05

## 评分规则
- 5 = 非常喜欢
- 4 = 经常吃 / 比较喜欢
- 3 = 会吃 / 一般
- 2 = 不太吃
- 1 = 讨厌 / 基本不吃

---

## 1. 蛋白质 / 肉类

### 牛肉
- 整体：一般，没有特别偏好
- 例外：卤牛腱子比较喜欢
- 现实限制：目前没有自己做过牛腱子，主要因为在日本比较难买到合适的大块牛腱

### 猪肉
- 经常吃

### 鸡肉
- 经常吃

### 鸭肉
- 基本不作为日常食材
- 原因：在日本不太好买

### 羊肉
- 基本不作为日常食材
- 原因：在日本不太好买

### 鱼类
- 三文鱼：吃
- 鳟鱼：可以
- 其他鱼：基本不吃

### 海鲜
- 虾：经常吃
- 螃蟹：不吃
- 贝类：不吃
- 鱿鱼：可以吃，但没有自己做过
- 章鱼：暂未明确偏好

### 其他蛋白质
- 鸡蛋：经常吃
- 豆腐：经常吃
- 豆制品（豆皮、腐竹、油豆腐等）：一般
- 内脏：基本不吃
- 例外：极偶尔吃过日本超市熟食猪肝

- 可以明确区分：口蘑、金针菇、香菇

- 有些菇口感比较怪，偶尔还会吃到像小碎石一样的东西，会影响食欲
- 因此不建议笼统推荐“蘑菇类”，最好具体到品种

## 4. 乳制品 / 加工食材 / 其他

- 芝士：一般只在韩式辣炒年糕等特定料理里加
- 牛奶：一般只在麻辣烫里加
- 黄油：一般只用于煎牛排
- 淡奶油：不用
- 酸奶：不用于做饭；早餐可搭配麦片 / granola
- 火腿 / 培根：愿意吃，但觉得日本超市常见款不好吃
- 香肠：有一款喜欢的，但不想经常吃
- 午餐肉：会吃，但觉得太贵
- 泡菜：韩国料理里可以
- 咖喱块：很久没吃，但不介意

## 7. 烹饪方式与复杂度

### 烹饪方式
- 炒：可用，评分待补
- 煎：5
- 煮：5
- 炖：4
- 蒸：4
- 烤箱：4
- 空气炸锅：无
- 火锅 / 麻辣烫：4
- 凉拌：会做凉面，但几乎没有自己做过凉拌菜
  - 顾虑1：不太会调凉拌汁
  - 顾虑2：担心判断食材是否变质
- 焖饭：3
- 汤面 / 汤粉：4
- 炒面 / 炒粉：4
- 一锅料理：4
- 腌制后再做：4
- 油炸：2

### 做饭习惯
- 可以接受提前腌 30 分钟
- 可以接受炖 1 小时以上，但更适合用电饭锅
- 可以接受洗较多锅具
- 工作日晚饭可接受最长约 45 分钟
- 周末愿意做复杂菜
- 可以一次做 2–3 顿的量

## 8. 近期真实饮食模式

最近更偏向“组合型做饭”，而不是严格按固定菜谱做。

常见形式：
- 意大利面 + 虾 + 西兰花等一起煮
- 火锅底料 + 现有肉 / 虾 / 蔬菜 / 主食一起煮
- 汤面 / 汤粉 + 蛋白质 + 青菜
- 杂粮饭 + 一个肉菜 + 一个蔬菜
- 乌冬 / 米线 + 蛋白质 + 蔬菜

### 已记录的模板型食谱
1. 番茄虾仁西兰花意面
2. 火锅底料一锅煮
3. 汤面 / 汤粉 + 肉 / 虾 + 青菜
4. 杂粮饭 + 一个肉菜 + 一个蔬菜
5. 乌冬 / 米线 + 蛋白质 + 蔬菜

## 9. 未来 GPT 推荐规则（初版）

每天推荐 3 个候选即可，目标是减少决策负担。

建议优先考虑：
- 5分食材优先
- 4分食材常用
- 3分食材正常可用
- 2分尽量少出现
- 1分默认不推荐
- 优先符合真实做饭习惯的组合型料理
- 工作日尽量控制在 45 分钟内
- 优先煎、煮、炖、蒸、一锅料理、汤面/炒粉
- 凉拌菜与油炸降低优先级
- 不要推荐奶油意面
- 不要笼统推荐“蘑菇类”，应具体到品种
- 鸭肉、羊肉、牛腱、馄饨等要考虑日本实际购买难度
