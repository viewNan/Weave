# Food preferences — public example

This file is a template. Keep actual food preferences and personal meal details
outside the public repository, for example in a separate private repository.

- Preferred ingredients: not configured
- Preferred cuisines: not configured
- Avoided ingredients / dietary restrictions: not configured
- Cooking time and equipment: not configured

The public application uses the neutral example in
`frontend/features/recipes/config/recipe-preferences.ts`. Real private files are
not imported automatically and are not required to build the public project.
