# 练习积分、统计与随机练习规则

本文件记录当前采用的产品规则，便于后续调整。技术与导入规范见
[practice.md](practice.md)。个人题库、练习数据和讨论原文不放在公开仓库。

## 两个独立的界面模式

**题库模式**是默认入口。分类按管理中设置的顺序排列，分类里的题目按
原始排序排列；打开、刷新或评级不会随机改动题库顺序。可以浏览要点、
查看历史、编辑内容，或者直接对某题练习评级。

点 **开始练习** 才进入随机练习模式。点 **返回题库** 随时恢复原始顺序。
这是同一页面内的独立模式，不修改数据库里的分类和题目排序。

## 正向积分与目标

每道题只有一个分数，名称为 **流畅进度**：

| 有效练习记录的评级 | 对积分的贡献 |
| --- | --- |
| 流畅 | 10 分 |
| 卡顿 | 0 分 |
| 不会 | 0 分 |
| 只勾选、尚未评级 | 0 分 |

- 起始 0 分，最高 100 分，不设每日计分上限。
- 分数为 `min(100, 有效流畅记录次数 × 10)`，不单独保存或逐次累加。
- 重复点击同一档位不是新记录，不能重复加分。真正再练一次要点
  **再练一次**，产生新的记录，再为这一条评级。
- 卡顿和不会不会扣掉此前记录贡献的积分。若修改、撤销、删除旧记录，
  则按剩余有效历史重算分数，因此纠错操作可能使分数下降；恢复也会重算。
- 100 分且最近一次有效评级为流畅：**目标达成**。
- 100 分但最近一次有效评级为卡顿或不会：**待复习**，积分仍保留。
- 新增一条未评级记录，不会清空最近一次有效评级或以前的积分。

100 分表示累计完成十次自评流畅的练习目标，不代表客观能力评估、
永久掌握或“完美”。同一天反复成功也可达标，这是当前选择的简单规则。

## 鼓励性展示与真实次数

题库使用紧凑摘要；以下完整信息在手机题目展开、练习卡片或详情中展示：

- 流畅进度与中性色进度条，例如 `40 / 100`。
- “再获得 6 次流畅记录，即可达到 100 分”。这是规则上的剩余成功次数，
  不是预测再练六次就一定会掌握。
- 最近一次有效评级、今日练习次数。
- **已练 N 次 · 查看次数**，点一下就能展开完整次数统计。

展开统计后分别显示带文字的 **流畅、卡顿、不会** 次数。仅勾选的记录单独
显示为未评级。统计是全部有效历史，不限于今天；软删除记录不计入，
恢复后重新计入。不能只用 `4/2/5` 或颜色让人猜含义。

分数不混入“努力分”。失败和卡顿仍贡献真实的总练习次数，既保留投入，
也不让“全是失败但已经100分”成为可能。完整历史继续可查、可纠错。

例如：流畅 4 次、卡顿 2 次、不会 5 次，共练 11 次，分数 40；再新增
一次不会后，共练 12 次、不会 6 次，分数仍为 40。

## 开始练习后的优先级与随机顺序

**范围是整个当前练习集，不限于第一个分类。**

1. 最近一次有效评级为 **不会** 的题排最前。
2. 其次是 **卡顿**。
3. 再是 **未评级**：包括从未练习或仅勾选、没有有效评级的题。
4. 最后是 **流畅**，不论进度是否到100分。

在每一档内部随机排列，不按历史失败次数或积分排序。随机打乱后再按
上述档位稳定排序；使用不重复的完整队列，不是有放回抽题。

当前轮的队列是一个快照：

- 点开始练习、点换一轮时重新产生随机顺序。
- 同一轮刷新数据、切后台再回来、修改备注、星标、筛选或查看要点不会
  重排尚未完成的题。普通浏览器刷新会回到题库模式，需要再点开始练习。
- **成功提交一次评级**后，该题移到本轮尚未评级的题后面，避免同一道
  不会的题持续占据开头。其余未完成题的相对顺序不变。
- 只勾选或点再练一次暂不移走，方便先勾选再为本次评级。
- 本轮已评的题仍留在队列末尾，可以主动再次练习，不会重复出现在队列里。
- 撤销最近的评级操作会恢复该题在本轮的原位置；数据库里的记录和积分
  同时按撤销后的历史重算。
- 开始练习、换一轮、返回题库、筛选、展开要点本身都不创建练习记录。
- 切换练习集会返回题库模式。处于练习模式时跨过日本时间凌晨4点，
  新学习日刷新后会开始一轮新的队列；题库模式仍保持原始顺序。
- 练习中新增/导入的题先追加到本轮队列，换一轮后再按评级参与随机排序。
  已归档或已移除的题从本轮消失。分类筛选和搜索只限制题库浏览；
  开始练习的范围始终是当前练习集的全部未归档题目。

没有新增“稍后再练”状态、错误惩罚分、记忆概率预测或自动复习算法。
本轮进度只在当前页面内保留，不跨设备保存；练习记录和积分来源仍在云端。

## 桌面与手机布局

共用同一份数据、计分、历史和轮次状态，仅表现层响应屏幕宽度。

| 场景 | 桌面（视口至少1024px） | 手机和平板（小于1024px） |
| --- | --- | --- |
| 题库 | 按分类标题分区的紧凑行列表，显示固定编号、题目、分数、次数入口、评级、要点与星标 | 按分类标题分区的紧凑折叠行，默认显示编号、题目、最近状态、分数、要点按钮和星标；点开显示其余操作 |
| 开始练习 | 左侧可滚动题目导航，右侧一张当前题目卡片 | 只显示一张当前题目卡片，不铺开全部题目 |
| 回答要点 | 每行/卡片一键弹窗，长内容在限定高度内滚动 | 每行/卡片一键弹窗，无需先展开题目 |
| 历史与具体次数 | 次数入口或详情按钮可打开原有详情 | 当前卡片一键展开次数；详情仍可查全部历史 |

顶部摘要压缩为“今日已练题数/总题数”和今日练习次数。搜索、分类、状态
筛选合并为紧凑工具栏。题库不再为每道题重复展开大进度卡和全部操作。

练习成功提交评级后，当前题进入已评队列，界面自动显示下一道未评题。
撤销评级会恢复历史、分数和原轮次位置，手机也会回到该题。仅勾选或点
“再练一次”不会提前切题。完成全部题目后显示明确的完成提示，不自动开新轮。
桌面可主动选择导航中的已评题再练；手机可返回题库展开指定题目，或换一轮。
切题与切换模式会回到内容顶部，不沿用上一题的滚动位置。

当前布局不新增数据库字段、记录或服务器接口。响应式组件位于
`frontend/features/practice/ui/PracticeViews.tsx`；轮次和网络状态仍由
`PracticeWorkspace.tsx` 统一维护。

## 后续修改位置与验证

| 要调整的规则 | 位置 |
| --- | --- |
| 每次流畅加分、满分 | `frontend/features/practice/domain.ts` 的 `FLUENT_POINTS`、`PASS_SCORE` |
| 分数、剩余次数、达标状态 | 同文件 `fluentProgress` |
| 排序档位 | 同文件 `practicePriority` |
| 随机队列、稳定顺序 | 同文件 `startPracticeRound`、`refreshPracticeRound`、`orderedPracticeItems` |
| 历史计数的数据库查询 | `frontend/features/practice/service.ts` 的 `dashboard` |
| 模式切换、展示和本轮已评状态 | `frontend/features/practice/ui/PracticeWorkspace.tsx` |
| 桌面/手机布局、单题卡片、题目导航 | `frontend/features/practice/ui/PracticeViews.tsx` |
| 中英文案 | `frontend/shared/i18n/messages.ts` |

改分值或阈值时，需要同时更新目标提示、进度条及本文档，不得只改常量后
留下界面的100分含义不一致。当前参数不需要设置页；也不需要新数据库迁移。
全部旧记录自动参与新的派生计算。

验证要求：真实 SQLite 服务测试覆盖累计次数、重复评级、修改/撤销/删除/
恢复、封顶和待复习状态；队列测试覆盖跨分类优先级、同档随机、无重复、
不修改原始数据、同轮稳定、已评后移、撤销恢复，以及切练习集和跨学习日。
手机界面应检查进入练习前后顺序独立、按钮不挤压、统计一键可达和中英显示。
